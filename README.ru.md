# Менеджер расширений OpenCode

**Русский** | [English](README.md)

Плагин для OpenCode Desktop, который добавляет в «Настройки» отдельную страницу **«Менеджер расширений»**. Через неё можно управлять MCP-серверами, плагинами и навыками, не редактируя `opencode.json` вручную.

## Что умеет

- **MCP-серверы**: локальные (`command`, `cwd`, переменные окружения) и удалённые (`url`, заголовки, OAuth-блок); включение и выключение без удаления записи.
- **Плагины**: npm-пакеты, локальные папки и записи-исключения вида `-package`; параметры плагина передаются как JSON-объект.
- **Маркетплейсы плагинов**: встроенный каталог Anthropic `anthropics/claude-plugins-official` доступен сразу, но ничего из него не устанавливается автоматически. Можно добавить свои маркетплейсы по GitHub-ссылке, URL или локальной папке, открыть каталог, установить плагин, обновить, отключить и удалить его.
- **Навыки**: папка с `SKILL.md` или отдельный файл `<id>.md`; полное редактирование текста, переименование, включение и отключение.
- **Две области**: глобальная (`~/.config/opencode`) и проектная (ближайшая папка `.opencode`, как у самого OpenCode).
- **Безопасная запись**: комментарии и форматирование JSONC сохраняются, перед каждой записью создаётся `.bak`, запись атомарная. При синтаксической ошибке в файле изменения блокируются.
- **Неизвестные поля сохраняются**: если в конфиге MCP-сервера есть поля, которых нет в форме, они остаются на месте.
- **Статусы MCP**: страница показывает, подключён сервер, запускается, выключен или требует входа.

## Маркетплейсы

Маркетплейс — это GitHub-репозиторий (или локальная папка) с файлом `.claude-plugin/marketplace.json`. Встроенный каталог Anthropic уже добавлен, но установка всегда выполняется вручную.

Из плагина маркетплейса в OpenCode переносятся совместимые части:

- MCP-серверы из `.mcp.json` или `mcpServers`;
- навыки из `skills/**/SKILL.md`;
- OpenCode-плагины, если репозиторий сам является плагином OpenCode.

Если у навыка нет корректного YAML frontmatter, он показывается в диалоге установки отдельно. Можно включить **«Адаптировать автоматически»** — менеджер добавит минимальный frontmatter с именем папки и первой строкой как описанием.

Команды, агенты, хуки и LSP Claude Code не поддерживаются — они показываются в предупреждении при установке.

Установленные из маркетплейсов плагины хранятся в реестре `~/.config/opencode/extensions-manager.json`. Их можно включать, отключать, обновлять и удалять. Удаление убирает только то, что добавил менеджер.

Если вставить ссылку на обычный GitHub-репозиторий, который не является маркетплейсом, менеджер попробует определить MCP-сервер или плагин OpenCode и предложит установить его.

Ссылка `https://github.com/upstash/context7` тоже работает: у этого репозитория есть собственный `.claude-plugin/marketplace.json`, поэтому он добавляется как отдельный маркетплейс, а `context7` устанавливается из его каталога. В итоге в конфигурацию попадает удалённый MCP `https://mcp.context7.com/mcp`.

## OAuth для MCP

В редакторе удалённого MCP-сервера есть три режима OAuth:

- **Автоматически** — поле `oauth` не записывается, OpenCode сам пытается зарегистрировать OAuth-клиент.
- **Свой OAuth-клиент** — можно задать `client_id`, `client_secret`, `scope`, `callback_port`, `redirect_uri` и `auth_server_metadata_url`.
- **Выключен** — записывается `oauth: false`, удобно для серверов с API-ключом в заголовках.

Сам вход через браузер выполняет OpenCode:

```powershell
opencode mcp auth context7
```

Команда открывает браузер и сохраняет токены в `~/.local/share/opencode/mcp-auth.json`. Посмотреть статус и выйти можно так:

```powershell
opencode mcp list
opencode mcp logout context7
```

В менеджере у сервера со статусом «нужен вход» есть кнопка, которая копирует команду `opencode mcp auth <имя>`. Сам браузер менеджер не открывает: GUI API OpenCode не предоставляет отдельный вызов OAuth.

Для Context7 OAuth не обязателен. Если нужен свой аккаунт или повышенные лимиты, проще выключить OAuth и добавить заголовок:

```text
CONTEXT7_API_KEY={env:CONTEXT7_API_KEY}
```

или

```text
Authorization=Bearer <ключ>
```

Ключ выдаётся на `https://context7.com/dashboard`.

## Установка

1. Соберите GUI:

   ```powershell
   npm install
   npm run build
   ```

2. Подключите папку плагина в глобальном конфиге `C:\Users\<вы>\.config\opencode\opencode.json`:

   ```json
   {
     "$schema": "https://opencode.ai/config.json",
     "plugins": [
       "C:\\Users\\<вы>\\Documents\\Opencode Plugin Manager"
     ]
   }
   ```

3. Перезапустите OpenCode Desktop.

Страница появится в **Настройки → Менеджер расширений**. Её же можно открыть из палитры команд.

## Разработка

```powershell
npm run typecheck   # проверка типов
npm run smoke       # серверная логика на временном проекте
npm run smoke:marketplace  # маркетплейс, установка и удаление на локальном каталоге
npm run build       # сборка dist/gui-experimental.cjs
npm run dev         # пересборка GUI при изменениях
```

После изменения GUI-кода нужен `npm run build` и перезапуск приложения. Серверная часть перезагружается по watcher'у OpenCode, но если плагин продолжает работать по-старому, перезапустите Desktop.

## Ограничения

- OAuth MCP выполняется командой `opencode mcp auth <имя>` (OpenCode также запускает вход автоматически при первом использовании). Менеджер только создаёт и правит конфигурацию; для сервера со статусом «нужен вход» есть кнопка, копирующая команду.
- Claude-специфичные параметры вроде `?client=claude-code-plugin` автоматически убираются из remote MCP URL при загрузке плагина и при установке из маркетплейса.
- Навыки с корректным frontmatter импортируются как есть; навыки без frontmatter по умолчанию пропускаются, но в диалоге установки их можно адаптировать автоматически.
- Навыки сканируются на одном уровне: `<skillsDir>/<id>/SKILL.md` и `<skillsDir>/<id>.md`. Отключённые навыки лежат в `<skillsDir>/.disabled`.
- Проектная область использует ближайшую найденную папку `.opencode`; если её нет, при первом изменении будет создана `<проект>/.opencode/opencode.json`.
- Плагин рассчитан на OpenCode 2.2.x и использует экспериментальный GUI API (`./gui-experimental`).
